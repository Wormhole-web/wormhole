# 🌀 WORMHOLE


## 🎬 1. Sobre el proyecto

**WORMHOLE** es una aplicación web que simula un videoclub especializado en películas de ciencia ficción.

Inspirado en el concepto de los agujeros de gusano, WORMHOLE pretende convertirse en una puerta de entrada a diferentes universos cinematográficos, permitiendo descubrir películas relacionadas con el espacio, los viajes en el tiempo, la inteligencia artificial, los mundos futuristas y otras temáticas propias de la ciencia ficción.

El proyecto ha sido desarrollado como parte de un trabajo académico, poniendo en práctica conocimientos de desarrollo web, diseño de interfaces UX/UI y organización de aplicaciones mediante componentes.

## 🚀 3. Identidad del videoclub

**Nombre:** WORMHOLE

**Temática:** Ciencia ficción.

**Concepto:** Un videoclub que conecta diferentes universos a través del cine.

**Eslogan:** Your gateway to another universe of cinema.

### Logotipo

El logotipo representa la identidad visual del videoclub y está inspirado en la idea de un agujero de gusano como portal hacia otros mundos.

## 🖥️ 4. Funcionamiento de la aplicación

La aplicación está dividida en diferentes secciones para facilitar la navegación:

- **Inicio (/):** Página principal donde se presenta WORMHOLE y su concepto.
- **Películas (/movies):** Sección dedicada al catálogo de películas de ciencia ficción.
- **Añadir película (/add-movie):** Formulario destinado a incorporar nuevas películas al catálogo.
- **Ubicación (/location):** Apartado con información sobre la ubicación y los horarios del videoclub.

## 💻 6. Instalación y ejecución

Para ejecutar WORMHOLE en tu ordenador, sigue estos pasos:

### Requisitos previos

- Node.js instalado.
- Git instalado.
- Un editor de código, como Visual Studio Code.

### Paso 1. Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/Wormhole-web/wormhole.git
```

### Paso 2. Acceder a la carpeta

```bash
cd wormhole
```

### Paso 3. Instalar las dependencias

```bash
npm install
```

### Paso 4. Ejecutar el proyecto

```bash
npm run dev
```

Una vez iniciado el servidor, Vite mostrará una dirección local en la terminal. Normalmente será algo así:

```text
http://localhost:5173
```

Abre esa dirección en tu navegador para acceder a WORMHOLE.
